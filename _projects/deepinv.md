DeepInverse is a Python package based on PyTorch to solve inverse problems with deep learning. 
Inverse problems resolution is mainly used in image reconstruction/restoration (see <a href="https://deepinv.github.io/deepinv/auto_examples/index.html">DeepInverse examples</a>). Inverse problems aim to understand  effects that generated the output. A classic example of inverse problem is finding the epicentre of an earthquake using seismograph data.
Inverse problem speaking for imaging, the output is a given image and it tries to recover the measurments that lead to this image formation. In MRI imaging, inverse problems are useful to improve image quality and details.

If you want to learn more about solving inverse problems, check <a href="https://deepinv.github.io/deepinv/auto_examples/basics/demo_quickstart.html">DeepInverse quickstart</a>.
